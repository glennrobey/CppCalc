# C++ Scientific Calculator

Calculator application implementing common arithmetic and scientific operations with a modular C++ backend.

## Features
- Basic arithmetic
- Scientific functions
- Expression evaluation
- Error handling

## Tech Stack
- C++
- CMake
- Drogon
- React
- TypeScript
- Vite
- Linux

## Build

```bash
cmake -B build
cmake --build build
```

## Run

```bash
./build/calculator
```
